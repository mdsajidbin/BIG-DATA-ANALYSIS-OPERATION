=====================================================================
HADOOP PROJECT EXECUTION COMMANDS
Project: E-commerce Sales Data Analytics
Operations: 3 MapReduce Jobs & 5 Pig Latin Tasks
=====================================================================

STEP 0: CLEAN PREVIOUS HDFS OUTPUTS (Run before starting)
---------------------------------------------------------------------
hdfs dfs -rm -r /ecommerce/mr_output_city
hdfs dfs -rm -r /ecommerce/mr_output_payment
hdfs dfs -rm -r /ecommerce/mr_output_category_avg
hdfs dfs -rm -r /ecommerce/pig_output

=====================================================================
PART A: MAPREDUCE OPERATIONS
=====================================================================

OPERATION 1: City Sales Analysis
---------------------------------------------------------------------
1. Compile:
javac -classpath "C:\hadoop\share\hadoop\common\*;C:\hadoop\share\hadoop\common\lib\*;C:\hadoop\share\hadoop\hdfs\*;C:\hadoop\share\hadoop\mapreduce\*" -d . CitySalesMR.java

2. Create JAR:
jar -cvf ecommerce_analytics_city.jar CitySalesMR*.class

3. Execute Job:
hadoop jar ecommerce_analytics_city.jar CitySalesMR /ecommerce/inputs/sales_data.csv /ecommerce/mr_output_city

4. View Output:
hdfs dfs -cat /ecommerce/mr_output_city/part-r-00000
